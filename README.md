# Hotel Reception Management System 🏨

A modern, premium web application designed to streamline hotel reception operations. Built with a focus on aesthetics and user experience, this system provides real-time insights into hotel performance, room management, and billing processes.

## ✨ Key Features

- **📊 Interactive Dashboard**: 
  - Real-time statistics for Bookings, Check-ins, and Occupancy.
  - Visual Breakdown of Room Status (Clean, Dirty, Inspected).
  - Premium "Blues Way" aesthetic with cohesive color palettes.

- **💵 Billing System**: 
  - Comprehensive billing and invoicing management.
  
- **🛌 Room Management**: 
  - Visual occupancy charts.
  - Daily sold-out room tracking.

- **🎨 Modern UI/UX**: 
  - Built with **Tailwind CSS v4** for a sleek, responsive design.
  - Smooth animations and glassmorphism effects.

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

Follow these steps to set up the project locally.

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/itsmeishwar/hotel-reception-management.git
   cd hotel-reception-management
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```
